Per compilare un programma in C da shell bisogna usare il comando
'gcc <nomeFile.c>', una volta eseguito questo comando verrà creato
un file chiamato 'a.out' che è un eseguibile (questo se non ci 
sono errori durante la compilazione).
Se si vuole dare un nome specifico al file eseguibile si può usare il
comando 'gcc -o <nomeEseguibile> <nomeFile.c>'.
Nel caso ci fossero anche più librerie, per non avere errori durante la compilazione
basta aggiungere il parametro '-lm' in coda al comando di compilazione.
Per eseguire il file basta semplicemente usare il comando './<nomeEseguibile>'
